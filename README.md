Welcome To Zach Lima's LeetCode Tester!

Runs on the .NET framework with C#, Python, and CSnakes (to pass info from Python to C#)

C# Core and LeetCode solutions with Python for Python LeetCode solutions.

I created this so I could have a place to test my LeetCode solutions offline, but it ended up being a way to teach myself how to integrate more than one language. 

Instructions to Run:
Run the Program.cs in the terminal, or build the project using and navigate to bin/Release/net9.0/win-x64, and look for the publish folder:
    dotnet publish -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true
